# Photo Organizer

[Windows · \[Eng\]](../README.md) | **Windows · [KR]** | [macOS · \[Eng\]](README_mac.md) | [macOS · \[KR\]](README_mac_KR.md)

Photo Organizer는 필름 사진 메타데이터 관리, 디지털 사진 LUT 적용, 자동 폴더 정리, RAW 원본 매칭, 파일 시간 관리, 중복 파일 검사, 자동 업데이트 등을 지원하는 Windows용 사진 관리 프로그램입니다.

현재 버전: **v2.0.0**

---

## 주요 기능

### 필름 사진 관리

- 여러 장의 사진을 한 번에 불러오기
- 사진 순서 변경
- 순차 촬영시간 적용
- 정확한 촬영시간 직접 입력
- 촬영시간을 EXIF 메타데이터에 기록
- 카메라 제조사 / 바디 / 렌즈 정보 기록
- 필름 종류 정보 기록
- Windows 파일 생성일 / 수정일 동기화
- 로컬 데이터베이스에서 필름, 카메라 제조사, 카메라 바디 검색 및 선택

### 디지털 사진 LUT

- JPEG / PNG / TIFF 지원
- `.cube` LUT 파일 지원
- LUT 강도 0–100% 조절
- 원본 이미지와 LUT 적용 이미지 나란히 미리보기
- 이전 / 다음 버튼을 이용한 여러 사진 탐색
- LUT 라이브러리 관리
- JPG / PNG / TIFF 형식으로 출력
- 출력 시 원본 이미지 형식 유지 가능

`저장` 기능은 원본 파일을 덮어쓰지 않습니다. 대신 원본 파일과 같은 폴더에 `_LUT`가 붙은 새 파일을 생성합니다.

예시:

```text
IMG_0001.jpg
IMG_0001_LUT.jpg
```

`다른 이름으로 저장`을 사용하면 저장 위치와 파일명을 직접 지정할 수 있습니다.

## 폴더 분류

사진을 다음 기준으로 자동 분류할 수 있습니다.

- 파일 확장자
- 촬영 날짜
- 카메라 모델
- 렌즈

이미 분류된 하위 폴더 안의 사진도 재귀적으로 다시 정리할 수 있습니다.

같은 이름의 파일이 이미 존재하는 경우 다음 중 하나를 선택할 수 있습니다.

- 자동 이름 변경
- 건너뛰기
- 덮어쓰기

> 폴더 분류 기능은 실제 파일을 이동합니다. 중요한 사진은 분류 전에 백업하는 것을 권장합니다.

## JPEG → RAW 원본 매칭

Photo Organizer는 JPEG 사진과 같은 파일명을 가진 RAW 파일을 찾아 해당 원본 파일을 자동으로 복사할 수 있습니다.

지원 RAW 형식 예시:

- CR3
- CR2
- NEF
- ARW
- RAF
- ORF
- RW2
- DNG

## 파일 시간 관리

여러 사진에 순차 촬영시간을 한 번에 적용할 수 있습니다.

필요한 경우 Windows 파일 생성일과 수정일도 함께 변경할 수 있습니다.

---

## 중복 파일 검사

Photo Organizer는 SHA-256을 이용해 동일한 파일을 식별합니다.

성능 향상을 위해 먼저 파일 크기를 기준으로 후보를 분류하고, 중복 가능성이 있는 파일에 대해서만 SHA-256 해시를 계산합니다.

## 설치 및 실행

Photo Organizer는 별도의 설치 프로그램이 필요하지 않습니다.

1. GitHub **Releases** 페이지로 이동합니다.
2. 최신 `PhotoOrganizer_v2.x.x.exe` 파일을 다운로드합니다.
3. 다운로드한 실행 파일을 바로 실행합니다.

Python은 별도로 설치할 필요가 없습니다.

최초 실행 시 Photo Organizer가 필요한 오프라인 데이터베이스와 업데이트 도우미 파일을 자동으로 준비합니다.

프로그램 데이터는 다음 위치에 저장됩니다.

```text
C:\ProgramData\PhotoOrganizer
```

이 폴더에는 다음과 같은 파일이 저장될 수 있습니다.

```text
cameras.json
films.json
fixed_lens_cameras.json
ui_settings.json
update_state.json
updater.exe
```

## 자동 업데이트

Photo Organizer는 프로그램과 데이터베이스의 자동 업데이트를 지원합니다.

프로그램 업데이트 과정:

1. 새 버전 확인
2. 새 프로그램 다운로드
3. SHA-256을 이용한 파일 무결성 검증
4. 내장 업데이트 도우미 실행
5. 현재 실행 중인 프로그램 종료
6. 기존 프로그램을 새 버전으로 안전하게 교체
7. 업데이트된 프로그램 자동 재실행

업데이트 도우미는 Photo Organizer에 포함되어 있으며 필요한 경우 프로그램 데이터 폴더에 자동으로 준비됩니다.

프로그램 업데이트에 실패할 경우 가능한 한 기존 프로그램을 그대로 유지하도록 설계되어 있습니다.

## 데이터베이스 업데이트

다음 데이터베이스는 프로그램 본체와 별도로 업데이트할 수 있습니다.

- 카메라 데이터베이스
- 필름 데이터베이스
- 고정렌즈 카메라 데이터베이스

업데이트된 데이터베이스는 로컬에 저장되므로 이후에도 오프라인으로 사용할 수 있습니다.

---

## LUT 라이브러리

LUT 파일은 기본적으로 다음 위치에 저장됩니다.

```text
Documents\Photo Organizer\LUTs
```

LUT 파일을 정리하기 위해 하위 폴더를 만들 수 있으며, Photo Organizer는 하위 폴더 안의 LUT 파일도 자동으로 검색합니다.

---

## 오프라인 사용

Photo Organizer에는 기본 카메라 및 필름 데이터베이스가 포함되어 있습니다.

프로그램을 최초 실행하면 필요한 로컬 데이터베이스 파일이 다음 위치에 자동으로 준비됩니다.

```text
C:\ProgramData\PhotoOrganizer
```

이를 통해 인터넷 연결 없이도 주요 사진 관리 기능을 사용할 수 있습니다.

인터넷 연결이 필요한 기능:

- 프로그램 업데이트 확인 및 다운로드
- 카메라 / 필름 데이터베이스 업데이트

## 화면 해상도 및 UI 배율

Photo Organizer는 프로그램 해상도와 UI 배율을 서로 독립적으로 설정할 수 있습니다.

특히 다음 환경에서 유용합니다.

- QHD 디스플레이
- 4K 디스플레이
- 서로 다른 DPI를 사용하는 멀티모니터 환경

프로그램은 이전 창 위치와 화면 설정도 기억합니다.

## 중요 안내

- 중요한 사진은 작업 전에 백업하는 것을 권장합니다.
- 폴더 분류 기능은 실제 파일을 이동합니다.
- 파일 시간 관리 기능은 Windows 파일 정보 및 EXIF 메타데이터를 변경할 수 있습니다.
- LUT 저장 기능은 원본 이미지를 보존하도록 설계되어 있지만, 중요한 원본 사진은 별도로 백업하는 것을 권장합니다.
- 프로그램 업데이트 과정에서 Photo Organizer가 잠시 종료된 후 자동으로 다시 실행될 수 있습니다.
