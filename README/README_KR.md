# Photo Organizer
Windows · [Eng](README.md) | **[Windows · [KR]]** | [macOS · [Eng]](README/README_mac.md) | [macOS · [KR]](README/README_mac_KR.md)

Photo Organizer는 필름 사진 메타데이터 관리, 디지털 사진 LUT 적용, 폴더 자동 분류, RAW 매칭, 파일 시간 관리, 중복 파일 탐색 등을 지원하는 Windows용 사진 관리 프로그램입니다.

현재 버전: **v2.0.0**

---

## 주요 기능

### 필름 사진 관리
- 여러 장의 사진을 한 번에 불러오기
- 사진 순서 변경
- 순차 촬영 시간 적용
- 정확한 촬영 시간 직접 입력
- EXIF 촬영 시간 기록
- 카메라 제조사 / 바디 / 렌즈 정보 기록
- 필름 종류 기록
- Windows 파일 생성일 / 수정일 동기화

### 디지털 사진 LUT
- JPEG / PNG / TIFF 지원
- `.cube` 형식 LUT 지원
- LUT 강도 0~100% 조절
- 원본 / LUT 적용 결과 비교 미리보기
- 여러 장의 사진 이전 / 다음 탐색
- LUT 라이브러리 관리
- JPG / PNG / TIFF 출력
- 원본 형식 유지 출력

`저장` 기능은 원본을 덮어쓰지 않고 원본 파일과 같은 폴더에 `_LUT` 파일을 새로 생성합니다.

예시:

```text
IMG_0001.jpg
IMG_0001_LUT.jpg
다른 이름으로 저장을 사용하면 저장 위치와 파일명을 직접 지정할 수 있습니다.

폴더 분류

사진을 다음 기준으로 자동 분류할 수 있습니다.

확장자
촬영 날짜
카메라 기종
렌즈

이미 분류된 폴더 내부의 사진도 다시 연속적으로 분류할 수 있습니다.

같은 이름의 파일이 존재할 경우 다음 처리 방식을 선택할 수 있습니다.

자동 이름 변경
건너뛰기
덮어쓰기

폴더 분류 기능은 실제 파일을 이동합니다. 중요한 사진은 별도 백업을 권장합니다.

JPEG → RAW 매칭

JPEG 파일명과 같은 RAW 원본을 찾아 자동으로 복사할 수 있습니다.

지원 예시:

CR3
CR2
NEF
ARW
RAF
ORF
RW2
DNG
파일 시간 관리

여러 사진에 순차적인 촬영 시간을 일괄 적용할 수 있습니다.

필요한 경우 Windows 파일 생성일 / 수정일도 함께 변경할 수 있습니다.

중복 파일 찾기

SHA-256 기반으로 동일한 파일을 찾습니다.

성능 향상을 위해 먼저 파일 크기로 후보를 분류한 뒤 필요한 파일만 해시 비교합니다.

Photo Organizer는 새로운 버전을 확인하고 자동 업데이트를 지원합니다.

업데이트 과정:

새 프로그램 다운로드

updater 실행

새 버전으로 안전하게 교체
새 버전 자동 재실행

업데이트에 실패할 경우 기존 프로그램은 그대로 유지됩니다.
